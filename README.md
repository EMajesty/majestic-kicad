# Majestic KiCad libraries

Reusable KiCad symbols and footprints collected from personal projects.

## Libraries

- `majestic.pretty`: consolidated footprint library
- `symbols/emission-engine.kicad_sym`
- `symbols/midilord.kicad_sym`
- `symbols/noot.kicad_sym`
- `symbols/platnam.kicad_sym`

The symbol libraries remain separated by source project because
`emission-engine` and `platnam` contain different definitions of
`TLV320ADC5140`.

## Sources

Content was copied from the `emission-engine`, `midicon`, `midilord`,
`nonstandard`, `noot`, and `platnam` repositories. Artwork footprints and the
third-party CM5 and Mega2560Pro libraries are intentionally excluded.
